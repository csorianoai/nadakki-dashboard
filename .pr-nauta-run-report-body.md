## Summary

- **Fix post-session crash (A):** On terminal run status (`completed` / `failed` / `blocked`), the live iframe is unmounted (`liveViewUrl → null`) instead of staying mounted after "Session Ended". `NautaLiveIframeBoundary` catches iframe render faults so `/nauta` does not white-screen.
- **Run report panel (B):** Two-column layout after completion — left: run summary (task, duration, steps, cost, status); right (50%): agent report with monospace output, copy/download, recordings, screenshot, and backend GAP callouts.
