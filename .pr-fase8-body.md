## Summary

Implementa los 5 features de agente AI que diferencian Nadakki Auto de portales tradicionales:

1. **AI Personal Shopper Persistente** — onboarding 3 pasos, `/autos/mi-shopper`, matches con score, badge en TopNav, sección landing
2. **Publicación 1-Click con AI** — `/autos/dealer/publicar-rapido` (upload → análisis → preview → publish)
3. **Chat AI 24/7 en Listings** — `VehicleChatWidget` bottom-right en VDP (Concierge global movido a bottom-left)
4. **Lead Scoring Dashboard** — `/autos/dealer/leads` con ranking hot/warm/cold y signals
5. **Analytics Insights AI** — `/autos/dealer/insights` con métricas, recomendaciones accionables, benchmarks, PDF semanal

## Backend endpoints consumidos

| Feature | Endpoints |
|---------|-----------|
| Personal Shopper | `POST /api/v1/autos_ai/buyer_shopper/register`, `POST .../refine`, `GET .../matches` |
| Publish 1-Click | `POST /api/v1/autos_ai/dealer_ai/publish_from_photos`, `POST .../publish/{id}` |
| Vehicle Chat | `POST /api/v1/autos_ai/concierge/message` (extend `vehicle_id`) |
| Lead Scoring | `GET /api/v1/autos_ai/dealer_ai/leads/priority` |
| Insights | `GET /api/v1/autos_ai/dealer_ai/insights` |

## Feature flags y modo demo
