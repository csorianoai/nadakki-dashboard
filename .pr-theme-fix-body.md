## Summary

Surgical fix for unauthorized global visual regression introduced by **PR #328** (`d368268`, 2026-07-17).

**Root cause:** Autos marketplace `ThemeProvider` / `TenantProvider` mounted in root `app/layout.tsx` wrote `data-theme` and `data-tenant` to `document.documentElement`, and autos CSS tokens lived on global `:root` / `[data-theme="dark"]`. That activated Forge dark rules (`[data-theme="dark"] .forge-app`) across Credit Hub / Forge.

**Not the cause:** `forge-tokens-v2.css` import (pre-existing since PR #35, May 2025). That file never defined `--brand` by design.
