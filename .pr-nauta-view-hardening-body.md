## Root cause (confirmed)

**Hypothesis 1 — CONFIRMED (primary crash)**

`NautaRunReportPanel.tsx` called `.toFixed()` on poll metrics without type coercion:

- `durationSeconds.toFixed(1)` (~line 93 pre-fix)
- `estimatedCostUsd.toFixed(4)` (~line 104 pre-fix)

`NautaLiveView.tsx` `applyPollData` assigned API fields with `??` only:

```ts
durationSeconds: data.duration_seconds ?? prev.durationSeconds
```

When GET `/api/v1/nauta/runs/{id}` returns numeric fields as **strings** (e.g. `"45.2"`), `??` keeps the string. On terminal transition the report panel mounts and throws:

`TypeError: durationSeconds.toFixed is not a function`

This is an **uncaught render throw** outside `NautaLiveIframeBoundary` → entire `/nauta` React tree unmounts → browser white screen ("This page couldn't load"). #255 iframe boundary could not catch it.

**Secondary — CONFIRMED**

`runReportUtils.ts` `collectBackendGaps()` accessed `artifacts.recordingUrls.length` without guarding malformed artifacts → throw if `recordingUrls` undefined.

**Hypothesis 2 — PARTIAL**

Async polling could call `setState` after unmount. Fixed with `mountedRef` + `pollGenerationRef` + timer cleanup.

**Hypothesis 4 — ADDRESSED**

Resume (`initialRunId`) now does a single GET first, only starts interval if still `running`; terminal runs render report/fallback without crash loop.

## Fix (defense in depth)

1. **`NautaViewErrorBoundary`** wraps cockpit scroll content — fallback "Algo falló al mostrar esta vista" + "Volver al Piso".
2. **`safeValues.ts`** + **`sanitizeLivePollSnapshot`** — coerce string metrics, output-dict/`outcome_text`, malformed artifacts.
3. **`NautaRunReportPanel`** — 100% null-safe render; pending output message + retry GET; cost gated to `platform_superadmin`.
4. **`NautaLiveView`** — stop polling on terminal/unmount; guarded setState; instrumented `console.error` via `logNautaViewError`.
5. Unit tests reproduce string-metric crash path.
