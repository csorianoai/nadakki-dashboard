# Phase 5 screenshots

Capture locally after enabling the feature:

1. Set in `.env.local`: `NEXT_PUBLIC_COMPETITIVE_RESEARCH_ENABLED=true`
2. Run `npm run dev`
3. Open `http://localhost:3000/competitor-research` (ensure a tenant is selected in the shell)
4. Save images for:
   - Tab **Quick Search** (sample domain + results)
   - Tab **Deep Analysis** (loading + result states optional)
   - Tab **Ask Anything** (sample chat)

Store PNGs in this folder (`docs/phase5/screenshots/`) and reference them in the PR description if required.
