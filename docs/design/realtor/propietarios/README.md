# Propietarios (O2-P-PROPIETARIOS)

Pantalla `/realtor/propietarios` sobre el armazón DL10A (nav-2); referencia visual `../DL10A/ref/propietarios.png`.
- Propietario = contacto con rol landlord (arrendador) o seller (vendedor), con su propiedad y su acuerdo de listing.
- Filtros: rol y estado del acuerdo. Ningún dato ni filtro de clase protegida (el idioma preferido tampoco filtra).
- Sin backend propio en la Ola 2: fuera de DEMO, «Sin datos todavía», sin cifras. DEMO solo con `NEXT_PUBLIC_REALTOR_ALLOW_DEMO="1"`.
- Fuera de alcance: el Listing Director (etapas del listing) del prototipo; esta pantalla cubre la tabla de propietarios.
