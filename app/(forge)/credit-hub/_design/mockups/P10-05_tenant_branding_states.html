Decisiones de mockup (para review de Cesar)

  • Sidebar nav nunca skeleton: la IA es invariable, el usuario no debe ver "loading" en la nav. Solo el sidebar header (logo+name del tenant) entra en estado loading.
  • Main content sí renderiza con default branding mientras fetch corre, en lugar de bloquear toda la página. Esto es el "chrome estable + slots fluidos" del REF-3 (Goldman Marquee).
  • Banner de error no es modal ni toast: es persistente hasta que el usuario haga retry o el fetch tenga éxito. El banker debe estar consciente del fallback durante toda la sesión.
  • Banner format ERR-YYYY-MM-DD-NNNN: matches el formato documentado en _API_CONTRACT.md §"MANEJO DE ERRORES".
  • Skeleton shimmer 1.4s linear: ligeramente más lento que el --forge-duration-base: 180ms porque es ambient, no transition. Aún respeta prefers-reduced-motion.
  • NO hay "Selecciona una institución": caso edge de tenantId vacío en JWT — bug de auth, no UX. Documentado para Phase 11. Si ocurre, banner rojo + UI deshabilitada.
  • Avatar "CS" en topbar es del usuario logueado, NO del tenant. No cambia entre estados.
  • El logo placeholder "C" en SUCCESS es un fallback visual del mockup (sin acceso a CDN aquí). En TSX real será <Image src={branding.logo_url} alt={branding.display_name}> con loader y `unoptimized` o config en `next.config.js`.

Cómo se traduce a TSX (preview del approach) 

// lib/credit-hub/hooks/useTenantBranding.ts
export function useTenantBranding(tenantId: string | null) {
  return useQuery({
    queryKey: ['tenant-branding', tenantId],
    queryFn: () => fetchTenantBranding(tenantId!),
    enabled: !!tenantId,
    staleTime: 5 * 60_000,        // 5min
    retry: 2,
    placeholderData: undefined,    // no use default while loading; show skeleton
  });
}

// components/forge/layout/ForgeCreditHubAppShell.tsx (simplified)
export function ForgeCreditHubAppShell({ children }) {
  const { tenantId } = useTenant();
  const { data: branding, isPending, isError, refetch } = useTenantBranding(tenantId);
  const effective = branding ?? DEFAULT_BRANDING;

  return (
    <div
      className="forge-app"
      data-tenant={branding?.tenant_id}              // only set when SUCCESS
      style={branding ? {
        '--forge-brand-500': branding.brand_primary,
        '--forge-brand-900': branding.brand_dark,
      } as CSSProperties : undefined}
    >
      <ForgeCreditHubSidebar
        tenantName={isPending ? null : effective.display_name}
        showHeaderSkeleton={isPending}
      />
      <div className="forge-main">
        <ForgeCreditHubTopbar
          logoUrl={isPending ? null : effective.logo_url}
          tenantName={isPending ? null : effective.display_name}
          locale={effective.locale}
          showLogoSkeleton={isPending}
        />
        {isError && <TenantBrandingErrorBanner referenceId={makeRef()} onRetry={refetch} />}
        <TenantBrandingProvider value={effective}>
          {children}                                   {/* main content can render */}
        </TenantBrandingProvider>
      </div>
    </div>
  );
}
