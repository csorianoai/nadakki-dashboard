## Summary

Frontend **Fase C-LIVE** para ejecución en vivo de Nauta: POST `mode: live`, polling cada 3s (máx. 200 intentos), iframe sandbox cuando llega `live_view_url`, banners amigables en 403.

**Contrato seguido:** [`docs/NAUTA_FASE_C_LIVE_REPORTE.md`](https://github.com/csorianoai/nadakki-ai-suite/blob/main/docs/NAUTA_FASE_C_LIVE_REPORTE.md) (backend `nadakki-ai-suite`).

**Build:** `npm run build` — **exit 0** (Next.js 16.2.4, verificado en rama).

## Contrato implementado

| Aspecto | Implementación |
|--------|----------------|
| **POST** `/api/v1/nauta/runs` | `{ task_name, mode: "live", engine_requested?, target_url?, dry_run: false }` |
| **Respuesta inmediata** | `{ id, status: "running", poll_url, live_view_url? }` |
| **GET** `/api/v1/nauta/runs/{id}` | Poll cada **3000 ms**, máx. **200** intentos (~10 min) |
| **Estados terminales** | `running` → `completed` \| `failed` \| `blocked` |
| **Auth** | `apiFetch` + Bearer JWT — **sin** header `X-Tenant-ID` |
| **403** | `protected_tenant` → *"Este tenant no permite ejecución live"*; `cloud_engine_requires_upgrade` → hint de upgrade |
| **iframe** | `sandbox="allow-scripts allow-same-origin"` (sin `allow-top-navigation`) |
| **Defaults QA** | task `platform_auditor_smoke_test`, target `https://app.nadakki.com` |
