## Summary

Corrige display del Run ID en live view y estado congelado cuando el poll falla (404, timeout, errores de red).

---

## ANTES / DESPUÉS

| Aspecto | ANTES | DESPUÉS |
|---------|-------|---------|
| **Run ID en UI** | `run.runId` en state pero **nunca renderizado** | Span `.live-view-run-id` con `data.id` **solo si** `run.runId` existe |
| **Antes del POST** | Sin run id (correcto en state) | Sin run id en pantalla (sin cambio de contrato) |
| **Después del POST** | `runId: data.id` en state, invisible | Muestra **exactamente** `response.id` |
| **`initialRunId`** | Id en state, invisible | Muestra el id al reanudar poll |
| **Poll 404 / error** | `pollError` + timers stop, **`status` quedaba `running`** → "Ejecutando…" congelado | `status: failed` + `failureCause` visible; badge **Falló** |
| **Poll 403** | Banner + `running` congelado | `status: blocked` + banner; deja de ejecutar |
| **Timeout 10 min** | `pollError` + `running` congelado | `status: failed` + mensaje en `failureCause` |
| **Error POST inicial** | `pollError` en idle | Sin cambio (`pollError` solo si `status === idle`) |
