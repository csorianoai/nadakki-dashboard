## Root cause (e0055501)

GET `/api/v1/nauta/runs/{id}` devuelve `outcome_text` en la **raíz** del payload, no solo en `artifacts.output`. `sanitizeLivePollSnapshot` solo leía `artifacts` → el panel y el `.txt` omitían tablas parciales válidas en runs `failed/task_unsuccessful`.

## Fix v2 — confianza calibrada

- **`runOutcome.ts` + `RunOutcomeHeader`**: fuente única de verdad para encabezados (panel + `.txt`).
- **`mergePollArtifacts`**: fusiona `outcome_text` y `last_step_summary` raíz con `artifacts`.
- **Degradación visual**: `run-report-output--caution` (borde/fondo `--warn` / `--pill-listo-*`) en parciales y fallidos con output.
- **Seguridad**: output en `<pre>` texto plano — sin markdown/HTML (auditado: no `dangerouslySetInnerHTML`).
- **Copiar reporte**: siempre `buildRunReportDownloadText` completo (incluye parciales).

## Matriz de estados

| Estado | Encabezado |
|--------|------------|
| `completed` | ninguno |
| `completed_partial` | detenida por usuario — resultado parcial |
| `failed` + output | ⚠ RESULTADO PARCIAL + causa + último paso |
| `failed` sin output | mensaje de causa + último paso (sin bloque vacío) |
