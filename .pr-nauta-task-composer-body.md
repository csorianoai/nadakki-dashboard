## Summary

Task composer frontend para **E16 Operador de Tareas Libres** — contrato `feat/nauta-freeform-e16` (nadakki-ai-suite, pendiente merge backend).

- Textarea **Asignar tarea** (max 2000) solo si `allows_freeform`
- POST live: con texto → `task_instruction`; sin texto → `task_name` template
- Errores 422/403 honestos (incl. credenciales → vault)
- Estado `pending_approval` + banner ámbar → Centro de supervisión
- Entregables al completar/fallar: `recordingUrls`, `screenshotUrl`, `output`, `lastStepSummary`

**Territorio:** `lib/nauta/**` únicamente. **Sin** `hooks/nauta/` (live client directo).

---

## Contrato backend

| Campo / error | UI |
|---------------|-----|
| `task_instruction` en POST | Solo E16 / `allows_freeform=true` |
| `invalid_task_instruction` (422) | Mensaje exacto de validación |
| `task_instruction_too_long` (422) | Límite 2000 caracteres |
| `instruction_contains_secret` (422) | *"La instrucción no puede contener credenciales — usa el vault."* |
| `freeform_not_allowed` (403) | Mensaje claro; sin estado congelado |
| `pending_approval` | Banner ámbar + link supervisión |
| `artifacts.*` en GET run | Sección Entregables |
